# Requirements

`main.txt` is the training installation entry point. It installs the local RLinf and DMuon packages and includes `embodied/models/dreamzero.txt` for DreamZero dependencies.

Create the environment and install FlashAttention separately using the commands in the setup guide. [Setup guide](../docs/SETUP.md)

Prepare RoboTwin in a separate environment following its official installation guide. [RoboTwin installation](https://robotwin-platform.github.io/doc/usage/robotwin-install.html)
